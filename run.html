Before you run

  1. Keep this page open with the screen on. Phone browsers stop GPS when the screen locks. This page asks the phone to stay awake; on iPhone also set Settings › Display & Brightness › Auto-Lock › Never for the race.
  2. Turn brightness down and close other apps. GPS with the screen on uses about 10–15% battery per hour.
  3. Strava: record the run in the Strava app as usual, in parallel with this page. Both can use GPS at once. If you have Strava Beacon (or Google Maps live location), paste its link above as a backup. Those keep working even if this page closes.
  4. If the page closes or the phone restarts, just open this same link again. Your race resumes where it was.
